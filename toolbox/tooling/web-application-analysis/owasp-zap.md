# OWASP Zap

[OWASP Zed Attack Proxy (ZAP)](https://www.zaproxy.org/) is a free, open-source DAST tool maintained by [Checkmarx](https://en.wikipedia.org/wiki/ZAP_\(software\)) and volunteers, designed to find web application vulnerabilities. As a man-in-the-middle proxy, it intercepts traffic to analyze and test applications for flaws like [SQL injection](https://www.wallarm.com/what/owasp-zap-zed-attack-proxy) and XSS.
