# DirBuster

{% hint style="info" %}
### Download & Install:

[https://sourceforge.net/projects/dirbuster/](https://sourceforge.net/projects/dirbuster/)

[OWASP DirBuster Project](https://owasp.org/www-project-dirbuster/)



Install:

```bash
sudo apt update && sudo apt install -y dirbuster
```
{% endhint %}

**DirBuster** is an older, Java-based, OWASP-maintained tool for brute-forcing directories and file names on web/application servers. It ships with its own set of wordlists generated by crawling the internet for real directory/file names, ranked by frequency of occurrence.

{% hint style="warning" %}
#### Legacy Tooling

DirBuster is effectively legacy at this point - [gobuster.md](gobuster.md "mention") and [ffuf.md](../web-application-analysis/ffuf.md "mention") are faster, actively maintained, and generally preferred for CLI-driven work. DirBuster still turns up occasionally in older labs, exam material, or as the GUI option of choice, which is the main reason to keep this reference around.
{% endhint %}

### Practical Notes

* <mark style="color:$primary;">**Recursion is on by default.**</mark> Unlike [gobuster.md](gobuster.md "mention"), DirBuster will automatically dive into any newly discovered directories unless `-R` is passed - this can make scans run considerably longer against large sites.
* <mark style="color:$primary;">**List-based vs. pure brute force.**</mark> DirBuster supports both a wordlist-driven scan and a true character-based pure brute force (generating every possible combination up to a given length) - the latter is thorough but extremely slow, and rarely worth it outside of very specific scenarios.
* <mark style="color:$primary;">**HEAD/GET auto-switching**</mark> can occasionally miss content on servers that respond differently to each method - if results look sparse, try forcing `-g` to use GET only.
* <mark style="color:$primary;">**Bundled wordlists.**</mark> On Kali, [dirbuster.md](dirbuster.md "mention")'s default lists live alongside the tool (and are also reused by other tools) under `/usr/share/wordlists/dirbuster/` - reach for `directory-list-2.3-{small,medium,big}.txt` depending on time available.
* <mark style="color:$primary;">**When to actually reach for this over Gobuster/Ffuf:**</mark> mainly when a GUI is genuinely preferred (e.g. demonstrating live results to a non-technical stakeholder), or when replicating an older walkthrough/exam guide that specifically calls for it.

## GUI Mode

Simplest way to run it - launches the graphical interface with fields for target URL, wordlist selection, thread count, file extensions, and scan type (list-based vs. pure brute force):

```bash
dirbuster
```

Or pre-populate the target URL when launching:

```bash
dirbuster -u http://SERVER_IP:PORT/
```

***

## Headless (Command-Line) Mode

Use `-H` to run without the GUI — results are auto-saved to a report on completion:

```bash
dirbuster -H -u http://SERVER_IP:PORT/
```

### With a Specific Wordlist

{% code overflow="wrap" %}
```bash
dirbuster -H -u http://SERVER_IP:PORT/ -l /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt
```
{% endcode %}

### With File Extensions

```bash
dirbuster -H -u http://SERVER_IP:PORT/ -e php,html,txt,bak
```

### Setting Threads

```bash
dirbuster -H -u http://SERVER_IP:PORT/ -t 50
```

### Saving a Report to a Specific Location

```bash
dirbuster -H -u http://SERVER_IP:PORT/ -r /root/loot/dirbuster-report.txt
```
