# 143, 993 - IMAP

IMAP (Internet Message Access Protocol) allows a mail client to read and manage messages that remain stored on the server, rather than downloading and deleting them the way POP3 does. Port 143 serves plaintext IMAP, while port 993 wraps the same protocol in TLS (IMAPS).

{% hint style="info" %}
#### Default Ports

143/tcp (IMAP), 993/tcp (IMAPS)
{% endhint %}

```
PORT    STATE SERVICE
143/tcp open  imap
993/tcp open  imaps
```
