# 110, 995 - POP

POP3 is a standard mail protocol used by local email clients to retrieve messages from a remote server over a TCP/IP connection. From an offensive perspective, it is often probed to find valid system credentials or to test for insecure authentication mechanisms.

***

## Banner Grabbing

Connecting to the service via Telnet on port 110 or openssl on port 995 (POP3S) allows us to identify the service banner.

```bash
telnet <TARGET_IP> 110
```

Common findings include identifying the server software, such as Dovecot, and determining if the server allows plaintext authentication or requires encrypted sessions (SSL/TLS).

***

## Basic Enumeration

User enumeration can sometimes be performed using the `USER` command. If the server is configured to provide specific error messages, a response of `+OK` might indicate a valid username, even before a password is provided.

{% hint style="warning" %}
#### Modern Confirgurations

Many modern configurations, such as the one found on this target, will disallow plaintext authentication on non-secure connections, returning an error such as: `-ERR [AUTH] Plaintext authentication disallowed on non-secure (SSL/TLS) connections.`



In such cases, further enumeration must be conducted over port 995 using an encrypted wrapper.
{% endhint %}
