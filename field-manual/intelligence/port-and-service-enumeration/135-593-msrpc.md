# 135, 593 - MSRPC

MSRPC (Microsoft Remote Procedure Call) is the mechanism Windows uses to let a program on one host request a service from a program on another, without either side needing to understand the network details itself. Port 135 is the RPC Endpoint Mapper, playing a similar role to `rpcbind` on Linux, and port 593 exposes the same functionality wrapped in HTTP (RPC over HTTP), often used to reach services such as Exchange through a firewall that only permits standard web ports.

{% hint style="info" %}
#### Default Ports

135/tcp (RPC Endpoint Mapper), 593/tcp (RPC over HTTP)
{% endhint %}

```
PORT    STATE SERVICE
135/tcp open  msrpc        Microsoft Windows RPC
593/tcp open  ncacn_http   Microsoft Windows RPC over HTTP 1.0
```

## Endpoint Mapper Enumeration

`rpcdump.py` queries the Endpoint Mapper directly and lists every RPC interface currently registered, along with its universally unique identifier (UUID) and the port or named pipe it's bound to.

```bash
clue@machine[~]$ rpcdump.py 10.129.14.128 | grep -i -A2 'DRSR\|LSARPC\|SAMR\|NETLOGON'

Protocol: [MS-DRSR]: Directory Replication Service (DRS) Remote Protocol
Provider: NTDSAI.DLL
UUID: E3514235-4B06-11D1-AB04-00C04FC2DCD2 v4.0
Bindings:
              ncacn_ip_tcp:10.129.14.128[49664]
```

{% hint style="info" %}
#### Note

Interfaces worth prioritising include `lsarpc` (policy and SID lookups), `samr` (local and domain account management), `netlogon` (the interface abused by ZeroLogon), and `drsuapi` (Directory Replication Service, abused for DCSync). Their presence tells you which follow-on tools and attacks are worth attempting once you have credentials.
{% endhint %}

***

## Null Session Enumeration

If null sessions are permitted, `rpcclient` allows a good deal of enumeration without any credentials at all.

```bash
clue@machine[~]$ rpcclient -U "" -N 10.129.14.128

rpcclient $> srvinfo
rpcclient $> enumdomusers
rpcclient $> querydominfo
rpcclient $> lsaquery
```

***

## Common Findings

{% hint style="danger" %}
#### Exposure

Leaving the RPC Endpoint Mapper reachable externally, or permitting null sessions internally, is a common finding in its own right and is also the entry point for several well-known coercion and relay attacks (PetitPotam, PrintNightmare, ZeroLogon) that rely on being able to reach specific RPC interfaces. Note the exposure even where a specific exploit isn't attempted.
{% endhint %}
