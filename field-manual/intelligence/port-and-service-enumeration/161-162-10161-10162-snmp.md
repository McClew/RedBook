# 161, 162, 10161, 10162 - SNMP

SNMP (Simple Network Management Protocol) is used to monitor and manage network devices such as routers, switches, printers, and servers. Devices expose management data hierarchically through Object Identifiers (OIDs), organised into a Management Information Base (MIB). Port 161 is used for polling an agent for data, port 162 receives trap messages (unsolicited notifications sent to a manager), and 10161/10162 are the equivalent ports for SNMP secured with TLS/DTLS.

{% hint style="info" %}
#### Default Ports

161/udp (agent polling), 162/udp (traps), 10161/udp and 10162/udp (secured equivalents)
{% endhint %}

SNMP has three versions in common use: v1 and v2c both rely on a plaintext "community string" for access control and carry no encryption, while v3 adds proper authentication and encryption.

{% hint style="warning" %}
#### Default Community Strings

`public` (read-only) and `private` (read-write) remain common on network hardware and are worth trying before anything else.
{% endhint %}

```
PORT    STATE SERVICE
161/udp open  snmp    SNMPv1 server
```

## Cheat Sheet

<table><thead><tr><th width="280">Action</th><th>Description</th></tr></thead><tbody><tr><td><code>snmpwalk -c public -v1 &#x3C;target></code></td><td>Walks the entire MIB tree using a known community string.</td></tr><tr><td><code>snmpwalk -c public -v2c &#x3C;target></code></td><td>The same walk, requesting the SNMPv2c dialect.</td></tr><tr><td><code>onesixtyone -c community.txt &#x3C;target></code></td><td>Brute forces community strings against a target.</td></tr><tr><td><code>snmp-check &#x3C;target> -c public</code></td><td>Produces a friendlier, categorised enumeration report than a raw walk.</td></tr><tr><td><code>nmap -sU -p161 --script snmp-* &#x3C;target></code></td><td>Runs the full set of SNMP-related Nmap scripts.</td></tr></tbody></table>

```bash
clue@machine[~]$ onesixtyone -c /usr/share/seclists/Discovery/SNMP/common-snmp-community-strings.txt 10.129.14.128

10.129.14.128 [public] Linux web01 5.4.0-97-generic #110-Ubuntu SMP
```

## Automated Enumeration

The Metasploit modules `auxiliary/scanner/snmp/snmp_login` and `auxiliary/scanner/snmp/snmp_enum` cover community string brute forcing and a broad information dump respectively, and are worth running alongside the manual commands above rather than instead of them.
