# 3389 - RDP

RDP (Remote Desktop Protocol) is Microsoft's protocol for full graphical remote access to a Windows host. It's a common lateral movement and initial access vector once valid credentials are obtained, and is one of the most frequently targeted services for brute forcing and vulnerability scanning wherever it's left exposed externally.

{% hint style="info" %}
#### Default Port

3389/tcp
{% endhint %}

```
PORT     STATE SERVICE
3389/tcp open  ms-wbt-server
```

***

## Fingerprinting

The `rdp-ntlm-info` script reveals the target's hostname, domain, and OS build without needing any credentials at all, which is often enough to confirm you're looking at a domain-joined host before attempting anything else.

```bash
clue@machine[~]$ nmap -p3389 --script rdp-ntlm-info 10.129.14.128

PORT     STATE SERVICE
3389/tcp open  ms-wbt-server
| rdp-ntlm-info:
|   Target_Name: INLANEFREIGHT
|   NetBIOS_Domain_Name: INLANEFREIGHT
|   NetBIOS_Computer_Name: WEB01
|   DNS_Domain_Name: inlanefreight.local
|   DNS_Computer_Name: web01.inlanefreight.local
|_  Product_Version: 10.0.17763
```

<table><thead><tr><th width="160">CVE</th><th>Description</th></tr></thead><tbody><tr><td>CVE-2019-0708</td><td>"BlueKeep", a pre-authentication remote code execution flaw in older, unpatched Windows versions.</td></tr><tr><td>CVE-2018-0886</td><td>CredSSP relay vulnerability affecting the authentication layer used by RDP.</td></tr><tr><td>CVE-2020-0609 / CVE-2020-0610</td><td>Remote code execution flaws in the RD Gateway component.</td></tr></tbody></table>

{% hint style="danger" %}
#### Caution

Exploiting BlueKeep and similar flaws carries a genuine risk of crashing the target. Confirm the vulnerability exists with a dedicated scanner script rather than a live exploit unless the client has explicitly authorised the risk in the Rules of Engagement.
{% endhint %}

## Pass-the-Hash & Restricted Admin Mode

By default, RDP requires an interactive password rather than an NT hash. Restricted Admin Mode, if enabled on the target, allows pass-the-hash authentication instead, at the cost of the connecting user not being able to access network resources using their credentials from within the session.
