# 194, 6667, 6660-7000 - IRC

**Internet Relay Chat (IRC)** is a plain-text, client-server chat protocol. On assessments it turns up in two contexts: a legitimate internal chat server, or - far more interesting - the **command-and-control channel for a botnet/backdoor**, since IRC's lightweight text protocol makes it a historically popular C2 transport for malware.

{% hint style="info" %}
The IANA-assigned port is **194/tcp**, but it requires root privileges to bind on Unix, so almost every real-world deployment instead uses **6667/tcp** (the de-facto standard) or another port in the **6660–7000** range. IRC-over-TLS commonly uses **6697/tcp**.
{% endhint %}

```
PORT     STATE SERVICE
6667/tcp open  irc
```

***

## Manual Interaction

```bash
nc -nv <TARGET_IP> 6667
```

Once connected, a minimal handshake is enough to get a server banner and join a channel:

```
NICK enumbot
USER enumbot 0 * :Enumeration
JOIN #test
LIST
```

* `JOIN #test` — attempts to join a channel; the server will report whether it exists.
* `LIST` — many servers will (or can be configured to) return the full list of active channels and topics, useful for spotting anything named after internal projects, or C2 channel names on a compromised host.
* `WHO #channel` / `NAMES #channel` — lists users currently in a channel.

***

## Automated

```bash
nmap -sV -p6667 --script irc-info,irc-botnet-channels,irc-unrealircd-backdoor <TARGET_IP>
```

* `irc-botnet-channels` looks for known botnet-style channel names.
* `irc-unrealircd-backdoor` checks for the infamous **UnrealIRCd 3.2.8.1 backdoor (CVE-2010-2075)**: the downloadable tarball for that version was trojaned to accept a magic string piped to the service, executing arbitrary shell commands — a classic HTB/CTF target and a real-world incident.

***

## Notes

* Banner-grab the server's `VERSION` reply and cross-reference it against known-vulnerable IRCd builds before attempting exploitation.
* On an internal engagement, an unexpected IRC service running on a workstation or server (rather than the dedicated chat server) is a strong indicator of **malware C2** and should be escalated as a potential compromise rather than treated as a routine finding.
