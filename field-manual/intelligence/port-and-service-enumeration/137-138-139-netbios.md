# 137, 138, 139 - NetBIOS

NetBIOS provides name resolution, datagram distribution, and session services for Windows networks, predating the widespread use of DNS and SMB directly over TCP/445. UDP 137 handles name resolution and registration, UDP 138 carries NetBIOS datagrams, and TCP 139 provides the NetBIOS Session Service, which is what older systems use to establish an SMB session before SMB was able to run directly over TCP.

{% hint style="info" %}
#### Default Ports

137/udp (Name Service), 138/udp (Datagram Service), 139/tcp (Session Service)
{% endhint %}

```
PORT    STATE SERVICE
137/udp open  netbios-ns
138/udp open  netbios-dgm
139/tcp open  netbios-ssn
```

## NetBIOS Name Table

Each entry in the name table pairs a name with a one-byte suffix indicating the type of service being registered.

<table><thead><tr><th width="120">Suffix</th><th>Meaning</th></tr></thead><tbody><tr><td><code>00</code></td><td>Workstation service</td></tr><tr><td><code>03</code></td><td>Messenger service</td></tr><tr><td><code>20</code></td><td>File server service</td></tr><tr><td><code>1B</code></td><td>Domain master browser</td></tr><tr><td><code>1D</code></td><td>Master browser</td></tr><tr><td><code>1E</code></td><td>Browser service elections</td></tr></tbody></table>

```bash
clue@machine[~]$ nbtscan 10.129.14.0/24

Doing NBT name scan for addresses from 10.129.14.0/24

IP address       NetBIOS Name     Server    User             MAC address
------------------------------------------------------------------------
10.129.14.128    WEB01            <server>  WEB01            00:15:5d:01:ab:02
```

***

## Relationship to SMB

The Session Service on TCP 139 largely exists to establish the same SMB sessions used on modern systems over TCP 445. For file-share enumeration, credential-based access, and everything past the name resolution stage, see the SMB article, since that's where the session ultimately leads.
