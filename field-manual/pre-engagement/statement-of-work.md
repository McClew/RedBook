# Statement of Work

The SOW is a specific contract for a single project or engagement. If multiple distinct tests are occurring (e.g., one Web App test and one External Network test), they often require separate SOWs to keep deliverables clear.

* **Purpose**: Defines the specific "what, when, and how much" of the project.
* **Key Components**:
  * **Scope & Objectives**: Explicitly lists the targets (URLs, IPs) and the goal of the test.
  * **Deliverables**: Usually includes the **Penetration Test Report** and an **Attestation Letter** (proof that a test was conducted).
  * **Timeline**: Start dates, end dates, and reporting deadlines.
  * **Cost**: Total price for the specific engagement.
  * **Resource Requirements**: What the tester needs from the client (e.g., credentials, VPN access, whitelisting).
  * **Client Responsibilities**: Stipulates that the client must provide necessary access for the test to occur.
