# S7-1500 PLCs

The S7-1500 is Siemens’ flagship Programmable Logic Controller (PLC). Introduced to replace the aging S7-300 line, it is designed for complex automation tasks (motion control, manufacturing, power plants).

For a pentester, the S7-1500 represents a shift from "Legacy OT" (no security) to "Modern OT" (security-by-design). Unlike its predecessors, it supports `S7CommPlus`, which incorporates cryptographic signing and anti-replay mechanisms.

## Communication Protocols

### S7Comm (Legacy)

Rarely used by 1500s unless "PUT/GET" communication is explicitly enabled for backward compatibility. This is unencrypted and unauthenticated.

### S7CommPlus (Modern)

The primary protocol for TIA Portal communication.

{% hint style="warning" %}
#### Security Note

Uses a proprietary handshake. In firmware V2.9+, it supports TLS-protected communication, making packet injection or unauthorised logic uploads significantly harder.
{% endhint %}

### Profinet (PN)

Used for real-time I/O. Attacks here usually involve Layer 2 flooding or DCP manipulation (see [scalance-switches.md](scalance-switches.md "mention")).

## Access Levels & Authentication

Siemens uses "Access Levels" to restrict what a user can do via the network or the built-in display:

* No Access (Password Protected): Requires a password even to _read_ data.
* Read Access: Can view variables/status but cannot change them.
* HMI Access: Limited to interacting with defined HMI variables.
* Full Access: Can upload/download code, stop/start the CPU, and change hardware config.

{% hint style="info" %}
#### Permissions Misconfiguration

If we find a PLC with No Password set for "Full Access," you can use the TIA Portal software (or specialised Python scripts like `snap7`) to completely "wipe" or "stop" the PLC.
{% endhint %}

***

## Physical Features & Security

* The Display: S7-1500s have a small color screen.
  * _Vulnerability:_ If physical access is possible, the display can be used to check the IP address, firmware version, and even reset the IP or factory settings if not password-protected.
* The Mode Switch: A physical switch (Run/Stop/MRES). If flipped to "Stop," the entire factory line ceases to function regardless of network security.
* SD Card (Memory Card): Holds the program and firmware. If the card is stolen, logic and passwords can be dumped offline.
